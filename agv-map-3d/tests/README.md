# tests — 自动化测试根目录

按 SPEC 第 15 章组织非浏览器自动化测试，目录划分固定如下：

- `unit/`：纯函数与契约单元测试（解析、坐标、几何、标签、相机、架构分层）。本 TASK 已落地基线测试。
- `fixture/`：固定回归样本与黄金数据（节点 ID、边 ID、期望坐标等）。
- `integration/`：真实样本 ready 后的集成计数断言（实例数、draw call、Text 上限）。
- `visual/`：`@playwright/test` 视觉基线截图（仅人工/CI 触发，本地基线不启动浏览器）。
- `performance/`：真实样本与八倍压力样本的帧时间、内存与加载耗时基线。

## 约束
- 本 TASK 的验证命令只运行 `unit/`，不启动浏览器、不依赖 GPU。
- 视觉与性能测试由后续 TASK 在 SPEC 固定环境下补齐。
