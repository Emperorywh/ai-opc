## 任务描述

### 可验证结果

真实样本的每个节点和每条边都生成一个稳定、轻量、与渲染技术无关的标签描述符，合计 4,810 个。节点标签与边标签分别遵守自己的定位公式，成对轨迹的边标签与 ribbon、边箭头使用同一车道偏移。

### 输入

- SPEC 第 2.2、2.5、2.6、5.2、7.1、9.3、11.2、15.2 节规定的名称、标签种类、锚点、偏移、层高和固定回归实体。
- TASK-005 交付的不可变领域节点、领域边和一次性场景坐标。
- TASK-006 交付的精确轨迹分组及每条边自身方向上的车道偏移语义。
- TASK-008 交付的节点类型、半径和稳定实体顺序。
- TASK-010 已验证的边方向与偏移车道一致性结果。

### 输出

- 1,767 个节点标签和 3,043 个边标签的不可变描述符，包含稳定 ID、所有者 ID、优先级类别、文本、世界锚点和局部屏幕偏移所需数值。
- 普通节点、作业节点和边标签之间明确且稳定的类别契约，供后续可见集排序直接消费。
- 节点标签与边标签相互独立的纯定位能力；边标签保留 LINE 与 BEZIER 的不同来源点规则。
- 覆盖真实样本总数、中文节点、固定直线/贝塞尔边、双车道偏移、稳定 ID 和非有限锚点异常的自动化测试。

### 实现约束

- 每个节点恰有一个标签；普通节点类别为 `node`，`work/park/charge` 类别为 `operational-node`。每条边恰有一个 `edge` 标签。
- 节点锚点使用节点场景 X/Z 和固定高度 `0.250m`；局部偏移使用该节点半径的 `1.5` 倍，语义为屏幕右下方，不能预先写成世界坐标偏移。
- LINE 标签来源点为边几何的 1/3 处；BEZIER 标签来源点为标准三次贝塞尔参数 `t = 2/3` 处，不得用弧长 2/3 替代。
- 边标签必须复用 TASK-006 已确认的配对与自身左侧车道偏移，再应用 SPEC 规定的场景平面固定偏移；不得重新判断轨迹是否重合，也不得只偏移 ribbon。
- 标签锚点高度固定为 `0.250m`，标签不得进入内容 bounds 或地面尺寸计算。
- 描述符 ID 与 owner ID 必须稳定且基于实体身份，禁止使用数组下标；文本必须保持原始 Unicode 内容，不得截断、转码或格式化数值名称。
- 节点和边的定位职责必须保持分离，禁止用包含隐式类型分支的巨型定位逻辑合并两套规则。
- 本任务不得创建 Troika Text、Three 对象、React 状态、空间索引或相机可见集，也不得回读原始 JSON。
- 任何锚点、偏移或描述符数值非有限时必须整体失败，禁止跳过标签。
- 新增或修改的代码必须使用多行简体中文注释说明标签分类、锚点公式、车道偏移复用与异常不变量；不得主动格式化无关代码。

### 验证方式

在 `C:\code\ai-opc\agv-map-3d` 执行：

```powershell
npm run lint
npm test -- --run
npm run build
```

- 正常路径：对真实样本生成描述符，断言总数 4,810，其中节点 1,767、边 3,043、作业节点类别 464、普通节点类别 1,303，并验证 ID 全部稳定且唯一。
- 正常路径：按完整 ID 和数据特征验证中文充电节点、固定直线边、固定贝塞尔边及两组精确反向边；预期文本、类别、来源点、车道偏移、固定平面偏移和高度符合 SPEC。
- 正常路径：重复构建同一输入，预期描述符顺序、ID 和全部数值完全稳定，且内容 bounds 不因标签产生变化。
- 关键异常路径：构造非有限来源点、无效半径或无法对应所有者的标签输入，预期返回结构化错误且不留下部分描述符。
- 预期结果：三个命令退出码均为 0，数量、分类、定位、稳定性和异常断言全部通过。

### 完成标准

- 真实样本 4,810 个候选标签全部具有可独立验证的轻量描述符，节点与边定位规则清晰分离。
- 相关 lint、测试和构建全部通过，此前 TASK 的地图、轨迹、几何和箭头行为未被破坏。
- 边标签与 ribbon、边箭头共享同一配对和车道偏移事实，没有重复轨迹识别或坐标转换。
- 没有提前创建文本对象、数组下标 ID、隐藏 fallback、标签参与 bounds 或跨层读取原始 JSON。
- 当前状态可建立仅覆盖 `agv-map-3d` 子目录的独立 Git checkpoint，并安全进入 TASK-012。

### 回退边界

回退本 TASK 的 Git checkpoint 时，只移除标签描述符、定位能力及其验证；TASK-001～TASK-010 已完成的工程、数据、领域、轨迹、ribbon、节点和两类箭头能力保持不变。
