## 任务描述

### 可验证结果

系统能够针对 4,810 个标签描述符，在不创建文字对象的前提下，根据当前视锥、投影字号、迟滞规则和稳定优先级生成最多 400 个标签的确定性可见集及差量结果。

### 输入

- SPEC §5.2、§11.2～§11.4、§12.2～§12.4、§15.2～§15.3。
- TASK-001～TASK-016 已交付的节点/边标签描述符、统一 lane offset、场景坐标和稳定实体 ID。
- TASK-017～TASK-020 已交付的相机投影、画布尺寸、controls 事件语义和 resize 行为。

### 输出

- 启动时基于 4m 网格建立只读空间索引，仅保存轻量标签描述符，不创建 Troika Text 或其他文字渲染对象。
- 通过外扩 1.5m 的占用 cell 视锥粗筛、描述符精确视锥测试和相机屏幕向上方向投影，计算每个候选标签的屏幕像素字号。
- 对未挂载/已挂载集合应用 10px 进入、8px 退出迟滞，按业务类别、屏幕中心距离和 ID 字典序稳定截断到 400。
- 输出确定性的目标 ID 集合和创建/销毁差量；初始标准 fit 后目标集合为空。
- controls 移动期间至多 10Hz 查询，controls end 与 resize 立即查询一次的调度契约。
- 覆盖空间索引、视锥、投影、阈值边界、稳定排序、数量上限和调度频率的自动化测试。

### 实现约束

- labels 模块只消费不可变描述符和显式相机数值输入，不得依赖 React、R3F、Troika 对象、原始 JSON 或全局相机单例。
- 投影字号必须使用相机局部 `+Y` 经 world quaternion 转换后的 screen-up；禁止把固定世界 `+Y` 当作屏幕竖直方向。
- 优先级固定为 operational node、普通 node、edge；同级先比较屏幕中心距离，再比较稳定 ID，不得使用数组下标、遍历时序或对象地址破坏确定性。
- 最大目标集合是 400，隐藏但已创建的文字对象不算懒加载；本任务不得预创建任何 Text。
- 移动频率限制必须由单一调度职责完成，end/resize 立即更新不得被 10Hz 节流吞掉；不得让每个标签注册事件或帧回调。
- 标签不参与内容 bounds、地面尺寸或相机 fit，且不得形成第二套坐标转换。
- 新增或修改的代码必须使用多行简体中文注释说明空间索引、投影字号、迟滞、稳定排序与调度不变量；不得主动格式化无关代码。

### 验证方式

1. 执行 `node --version`，预期为 `v24.16.0`；执行 `npm ci`，预期成功。
2. 执行 `npm run lint`、`npm test -- --run` 和 `npm run build`；命令不得启动浏览器，预期全部通过。
3. 正常路径：以真实样本描述符、标准 fit、放大视图和超过 400 个候选的合成视图运行纯计算；预期初始集合为 0，放大后集合不超过 400，类别/距离/ID 顺序稳定，重复输入得到完全相同的 ID 与差量。
4. 关键异常路径：验证 9px→10px、9px→8px 的进入/退出边界、视锥边缘 cell、相机滚转后的 screen-up、快速 change 后 end、resize 与大量同距候选；预期无抖动、无固定世界轴误判、无漏掉最终立即更新且不突破上限。
5. 本任务的可见集是纯计算结果，不要求 Coding Agent 启动浏览器；如用户人工观察调试视图，结果仅作为补充，不替代上述自动断言。

### 完成标准

- 4,810 个描述符的空间索引、投影筛选、迟滞、稳定排序、400 上限和查询调度全部可独立验证。
- 正常及关键边界自动化测试通过，且本任务未创建任何文字渲染对象。
- TASK-001～TASK-020 的数据、场景、相机和无障碍行为没有回归。
- 不存在全量隐藏 Text、逐标签事件/帧回调、非确定排序、重复坐标转换或跨层缓存。
- 可以创建仅包含 TASK-021 标签可见集能力及其测试/必要文档的 Git checkpoint，安全进入 TASK-022。

### 回退边界

回退 TASK-021 checkpoint 只移除标签空间索引、可见集、差量与查询调度；此前的标签描述符、静态场景和相机浏览保持完整，且不会遗留已挂载文字资源。父级 Git 的 checkpoint 与回退范围仅限 `agv-map-3d` 子目录，不得影响其他目录。
