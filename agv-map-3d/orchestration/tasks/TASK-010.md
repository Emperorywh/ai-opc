## 任务描述

### 可验证结果

每条经过校验的 LINE 或 BEZIER 边都沿自己的行驶方向生成一个箭头，箭头准确位于最终偏移车道的 40% 弧长处，并针对短边按比例收缩。真实样本稳定得到 3,043 个边箭头，最短 0.04m 反向边对的箭身不会越过各自起点。

### 输入

- SPEC 第 2.3、2.4、2.6、5.2、7、9、10、15.2 节规定的边方向、颜色、轨迹、弧长、尺寸和回归样例。
- TASK-005 交付的不可变领域边和一次性场景坐标。
- TASK-006 交付的最终单车道或双车道偏移折线、累计弧长、切线和轨迹配对语义。
- TASK-007 交付的 ribbon 几何结果及统一车道偏移事实。
- 此前 TASK 已交付的统一视觉常量、结构化几何错误和线性 sRGB 颜色规则。

### 输出

- 对全部边生成的箭头实例矩阵和实例颜色数据，实例顺序与来源边之间具有稳定、可验证的对应关系。
- 可供后续统一场景范围计算使用的边箭头真实几何范围贡献。
- 沿偏移后折线按累计弧长定位、取得有效切线并生成矩阵的纯数据契约。
- 覆盖 LINE、BEZIER、双车道、最短边、自适应长度、颜色和无有效切线异常的自动化测试。

### 实现约束

- LINE 与 BEZIER 必须共享 SPEC 规定的局部朝 `+X` 单位三角形和同一套实例数据契约，不得按边类型产生两套箭头语义。
- 箭头必须复用 TASK-006 的偏移后折线与累计弧长，不得重新采样、重新判断重合轨迹或让箭头留在未偏移中心线上。
- tip 固定位于总弧长 40% 处；必须按累计弧长定位，禁止把贝塞尔参数 `t = 0.4` 当成弧长比例。
- 箭头长度必须为 `min(0.30m, totalArcLength × 0.32)`，X/Z 等比缩放；短边不得使用固定 0.30m 长度。
- 位置高度固定为 `0.014m`，旋转使用箭头所在折线段的单位场景切线与 `atan2(-tz, tx)`；矩阵采用列主序 `T × R × S`。
- 箭头始终从边自身 start 指向 end；`isBackEdge` 只能选择该边颜色，不得改变点序、切线、旋转、位置或配对判断。
- 切线长度不大于 `1e-9m`、累计弧长无效或任何输出非有限时必须整体失败，不得选择相邻段或零角度降级。
- 本任务只生成纯数据，不创建 Three 对象、React 状态或渲染组件。
- 新增或修改的代码必须使用多行简体中文注释说明弧长定位、短边缩放、切线方向与异常不变量；不得主动格式化无关代码。

### 验证方式

在 `C:\code\ai-opc\agv-map-3d` 执行：

```powershell
npm run lint
npm test -- --run
npm run build
```

- 正常路径：对真实样本构建边箭头，断言实例数为 3,043、矩阵长度为 `3,043 × 16`、颜色长度为 `3,043 × 3`，所有矩阵、颜色和范围均为有限数。
- 正常路径：按完整 ID 与几何特征检查固定直线边、固定贝塞尔边、两类精确反向重合对和最短反向边对；预期箭头沿各自 start 到 end，且成对箭头位于各自偏移车道。
- 正常路径：对 0.04m 最短边断言箭长为 `0.0128m`、tip 位于 `0.016m` 弧长处，箭身不越过起点；对贝塞尔边断言 tip 由累计弧长而非参数 0.4 决定。
- 关键异常路径：构造零切线、无效累计弧长或非有限采样点，预期返回结构化几何错误且不产生部分实例数组。
- 预期结果：三个命令退出码均为 0，计数、方向、弧长定位、短边、自车道偏移和异常断言全部通过。

### 完成标准

- 每条真实样本边都有且只有一个方向正确的箭头，最短边和贝塞尔边的定位与尺寸规则通过自动化验证。
- 相关 lint、测试和构建全部通过，此前 TASK 的节点、轨迹、ribbon 和节点箭头行为未被破坏。
- 边箭头与 ribbon 共享同一偏移折线和累计弧长，没有第二套采样、配对、坐标或颜色规则。
- 没有固定短边箭长、无切线 fallback、按 `isBackEdge` 反转方向或跳过坏边的临时逻辑。
- 当前状态可建立仅覆盖 `agv-map-3d` 子目录的独立 Git checkpoint，并安全进入 TASK-011。

回退本 TASK 的 Git checkpoint 时，只移除边箭头实例数据、范围贡献及其验证；TASK-001～TASK-009 已完成的工程、数据、领域、轨迹、ribbon、节点和节点箭头能力保持不变。
