## 任务描述

### 可验证结果

此前生成的节点、ribbon、两类箭头和标签结果被汇总为渲染管线唯一消费的不可变场景模型。该模型包含完整元数据、显式坐标变换、最终 typed array、数值内容范围和诊断计数，并能在交付前自校验所有长度、有限性与计数关系。

### 输入

- SPEC 第 4.1、5.2、6、7、8、9、10、11.2、12.1、14.2、15.3 节规定的场景模型、数组布局、范围和诊断契约。
- TASK-005 交付的地图元数据、不可变领域地图和场景原点。
- TASK-006 交付的轨迹分组诊断与偏移后中心线。
- TASK-007 交付的单一 ribbon 顶点、颜色和几何范围。
- TASK-008～TASK-010 交付的节点、节点箭头和边箭头实例数据及其真实范围贡献。
- TASK-011 交付的全部标签描述符。

### 输出

- 一个作为后续 worker、渲染、相机和标签系统唯一输入的不可变场景模型契约。
- 地图 ID、地图名、版本及绝对世界原点等可追溯元数据。
- 节点、节点箭头、边箭头、ribbon 的最终 typed array，以及全部 4,810 个标签描述符。
- 合并最终双车道 ribbon、两类箭头和节点圆柱真实几何后的数值内容 bounds；明确排除标签和 Ground。
- 节点数、节点箭头数、边箭头数、ribbon 顶点数、标签候选数和成对轨迹数的只读诊断快照。
- 对数组长度、矩阵布局、颜色布局、有限数、bounds 和诊断关系进行整体拒绝式校验的自动化测试。

### 实现约束

- 后续箭头、标签、camera fit 和渲染资源必须只消费本场景模型，不得重新访问领域边、领域节点或原始 JSON 推导第二套结果。
- 矩阵数组长度必须为对应实例数乘 16，颜色数组长度必须为对应实例数乘 3，ribbon position/color 长度必须与非索引顶点数一致。
- 所有矩阵保持 Three Matrix4 兼容列主序，所有颜色保持线性 sRGB `[0,1]` 浮点值；汇总阶段不得二次转换坐标或颜色。
- 内容 bounds 必须覆盖 lane offset 后的 ribbon、两类箭头和节点圆柱真实范围，不得只使用节点坐标，也不得纳入标签或 Ground。
- 真实样本诊断必须至少满足：节点 1,767、节点箭头 464、边箭头 3,043、标签 4,810、成对轨迹 979；ribbon 顶点数由实际三角化结果给出。
- 模型不得携带原始 DTO、未消费业务字段、Three 对象、React 状态、隐藏缓存或可变全局引用。
- typed array 的所有权和可转移缓冲区集合必须显式且无重复；本任务只建立传输契约，不执行跨线程传输。
- 任一数组长度、诊断计数、数值有限性、bounds 顺序或元数据不一致时必须拒绝整个模型，不得修剪、补零或输出部分场景。
- 新增或修改的代码必须使用多行简体中文注释说明模型所有权、数组交叉校验、内容范围与整体拒绝不变量；不得主动格式化无关代码。

### 验证方式

在 `C:\code\ai-opc\agv-map-3d` 执行：

```powershell
npm run lint
npm test -- --run
npm run build
```

- 正常路径：对真实样本汇总模型，交叉断言元数据、场景原点、五类数组长度、4,810 个标签、979 个配对轨迹和全部有限数。
- 正常路径：用最终几何逐项验证内容 bounds，预期覆盖 ribbon、节点和两类箭头的极值，且添加或移除标签不会改变 bounds。
- 正常路径：枚举可转移缓冲区，预期每个最终 typed array 的 ArrayBuffer 恰好出现一次，不包含描述符或其他不可转移对象。
- 关键异常路径：分别篡改矩阵长度、颜色长度、ribbon 顶点计数、bounds 极值和诊断计数，预期整体拒绝并给出可定位的结构化错误。
- 关键异常路径：注入 NaN、Infinity、重复缓冲区或缺失元数据，预期不返回任何可用场景模型。
- 预期结果：三个命令退出码均为 0，场景模型的完整性、唯一性、范围与拒绝式校验全部通过。

### 完成标准

- 此前全部渲染数据已汇总为唯一、不可变、自校验且可转移的场景模型。
- 相关 lint、测试和构建全部通过，此前 TASK 的样本身份、领域语义和各类几何结果未被破坏。
- 内容 bounds、诊断和数组长度彼此一致，不存在部分模型、重复派生、原始 DTO 泄漏或 Three/React 跨层耦合。
- 所有异常均在进入 worker 传输和渲染层前稳定失败，不包含补零、截断或默认值逻辑。
- 当前状态可建立仅覆盖 `agv-map-3d` 子目录的独立 Git checkpoint，并安全进入 TASK-013。
