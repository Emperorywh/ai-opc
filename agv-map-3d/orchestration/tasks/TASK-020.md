## 任务描述

### 可验证结果

不依赖指针设备的用户可以聚焦地图并通过键盘完成平移、缩放、旋转和复位；页面同时提供可读的地图摘要、颜色图例与操作说明，减少动态效果的系统偏好不会改变最终视图或功能。

### 输入

- SPEC §1.2～§1.3、§7.2、§12.4～§12.5、§13。
- TASK-017 的 fit、clamp 与动态裁剪纯计算能力。
- TASK-019 的单一相机浏览状态、导航标记及 Home 复位能力。

### 输出

- 可聚焦的地图外层语义，其可访问名称至少包含地图名、节点数、边数和完整操作提示。
- 方向键按当前相机平面的 right/forward 平移当前距离的 5%，`+/-` 按 0.9/1.1 缩放，`Q/E` 每次绕 target 旋转 5°，Home 执行标准复位。
- 所有键盘动作复用 TASK-019 的相机状态、边界限制、导航标记和裁剪更新，不产生第二套相机状态。
- 静态颜色图例、纯文本操作说明，以及 `prefers-reduced-motion: reduce` 时关闭阻尼但保持功能和最终结果不变的行为。
- 键位映射、焦点边界、重复按键、默认浏览器行为抑制范围和减少动态偏好的自动化测试与人工无障碍验收。

### 实现约束

- 键盘层只能表达用户意图并调用已有相机用例；不得复制 target clamp、fit、near/far 或矩阵计算。
- 每个被消费的键盘操作在完成同一相机状态更新后显式请求 demand 帧；未消费按键不得触发渲染。
- 平移方向必须来自当前相机平面，不能写死世界轴；每次操作后的目标和相机位置仍须满足 TASK-019 不变量。
- 仅在地图容器拥有焦点且键位被本系统消费时阻止默认行为，不得劫持页面全局键盘输入。
- aria 文本和图例必须消费 ready 状态中的只读元数据与计数，不得回读样本 JSON 或维护人工同步副本。
- reduced-motion 只改变阻尼过程，不得改变允许的操作、最终相机位置、视觉内容或启用自动低质量模式。
- 不得引入对象选择、tooltip、业务弹窗、i18n、主题切换或旧键位兼容分支。
- 新增或修改的代码必须使用多行简体中文注释说明键盘意图映射、焦点边界、状态复用与 reduced-motion 不变量；不得主动格式化无关代码。

### 验证方式

1. 执行 `node --version`，预期为 `v24.16.0`；执行 `npm ci`，预期成功。
2. 执行 `npm run lint`、`npm test -- --run` 和 `npm run build`；命令不得启动浏览器，预期全部通过。
3. 正常路径：在非浏览器测试环境中向已聚焦地图发送全部规定键位，预期相机意图的方向、步长、比例和角度准确，Home 与 TASK-017 标准 fit 一致，aria 摘要含真实地图元数据和计数。
4. 关键异常路径：覆盖容器未聚焦、输入来自其他可编辑控件、未知键、长按重复、边界处继续平移和 reduced-motion 切换；预期不劫持无关输入、不越界、不重复维护状态，关闭阻尼后最终视图不变。
5. 人工无障碍验收仅由用户执行，Coding Agent 不启动浏览器：用户只使用键盘聚焦地图并完成方向键、`+/-`、`Q/E`、Home 操作，读取图例和操作说明，并切换减少动态偏好；预期焦点可见、操作可达、文本准确且没有页面级键盘冲突。

### 完成标准

- 键盘导航、焦点语义、地图摘要、图例和 reduced-motion 行为全部可验证。
- 自动化测试通过，用户已记录键盘与无障碍人工验收结果。
- TASK-001～TASK-019 的相机、场景和数据行为没有回归。
- 不存在全局键盘劫持、第二套相机逻辑、重复元数据、隐式键位或兼容旧行为。
- 可以创建仅包含 TASK-020 键盘与无障碍结果的 Git checkpoint，安全进入 TASK-021。

### 回退边界

回退 TASK-020 checkpoint 只移除键盘入口、无障碍摘要、图例和 reduced-motion 适配；TASK-019 的指针相机浏览及此前静态场景仍完整可用。父级 Git 的 checkpoint 与回退范围仅限 `agv-map-3d` 子目录，不得影响其他目录。
