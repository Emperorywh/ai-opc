## 任务描述

### 可验证结果

系统能够以 SceneModel 中唯一的最终内容包围盒为输入，确定有限地面、标准 3/4 初始视图和动态裁剪面；在宽、窄视口下都能完整容纳地图内容，且所有距离与裁剪值均由该权威范围推导。

### 输入

- SPEC §4.1、§5.2、§6、§7.1、§8～§10、§12.1～§12.3、§15.2～§15.3。
- TASK-001～TASK-011 已交付的严格样本边界、统一场景坐标、最终节点/车道/两类箭头几何数据及其有限数不变量。
- TASK-012 已在 SceneModel 中汇总最终 ribbon、节点圆柱和两类箭头的真实范围，交付排除标签与 Ground 的唯一 `contentBounds`；TASK-013～TASK-016 已保持该契约贯穿 worker、资源和加载边界。
- 已确认的全局边界：实际实现工程为当前仓库；只做本地运行，不设计 CSP 响应头或生产部署验证。

### 输出

- 校验并消费 TASK-012 的唯一数值内容包围盒，后续地面、fit 与裁剪均共享该输入，不另建几何范围。
- 依据内容尺寸和固定规则得到有限地面范围，并能向后续场景层交付地面描述。
- 针对有效画布宽高比得到标准 3/4 相机位置、观察目标、拟合半径与距离；首次非零尺寸和未发生用户导航的 resize 可重复得到同一结果。
- 从内容和地面联合范围推导动态 near/far，并保证所有合法输入满足 `0 < near < far`。
- 覆盖宽屏、窄屏、非零 Y 几何范围、地面扩张、观察点前后深度及非法数值输入的自动化测试和必要说明。

### 实现约束

- 内容范围的计算与所有权继续归 TASK-012；本任务不得遍历几何重新计算、退化为节点坐标范围，或维护供相机使用的第二套 bounds。
- 地面每侧 padding 固定为 `max(5m, max(contentWidth, contentDepth) × 10%)`；地面参与裁剪推导但不参与 fit。
- fit 必须先固定 SPEC 的 50° FOV、60° polar、45° azimuth，再按受限 FOV 与目标到扩张包围盒八角的最大距离求相机距离；扩张量为 0.50m、margin 为 1.10。
- near/far 必须按相机空间深度和当前拟合半径推导，不得使用任意大常量、无限地面或无限 far plane。
- 地面与相机模块只消费 SceneModel 的只读数值范围；不得回读原始 JSON/几何数组、创建第二套坐标转换或依赖 R3F 组件状态。
- 首次 fit 只能在画布尺寸非零且场景数据 ready 后提交；无效输入必须被明确拒绝或保持未提交，禁止产生 NaN/Infinity。
- 新增或修改的代码必须使用多行简体中文注释说明地面推导、fit 球心、裁剪深度与无效输入不变量；不得主动格式化无关代码。

### 验证方式

1. 执行 `node --version`，预期为 `v24.16.0`；执行 `npm ci`，预期严格按 lockfile 安装成功。
2. 执行 `npm run lint`、`npm test -- --run` 和 `npm run build`；这些命令不得启动浏览器，预期全部成功。
3. 正常路径：用真实样本 SceneModel 的 `contentBounds` 和至少一组非方形合成数值范围验证地面 padding、3/4 方向、fit 距离和 near/far；预期不回读几何，扩张范围八角投影满足 `|NDC.x| <= 0.92`、`|NDC.y| <= 0.92`，且地面不改变 fit 结果。
4. 关键异常路径：覆盖零尺寸画布、非有限范围、退化范围、相机空间中存在非正深度及极窄视口；预期不提交非法相机状态，合法分支的 near 下限为 0.02 且始终小于 far。
5. 本任务尚不交付 R3F 场景，不设置界面或视觉完成条件，也不启动浏览器；宽、窄视口完整性由投影数学断言独立证明，对应画面在 TASK-018 装配静态场景后再由用户人工验收。

### 完成标准

- TASK-012 的唯一内容范围被正确消费，地面、fit 与动态裁剪形成一个可复用且可独立验证的数据闭环。
- 正常路径和关键异常路径的非浏览器自动化验证全部通过，当前结果不依赖后续场景才能证明完成。
- TASK-001～TASK-016 的全部行为及自动化测试未被破坏。
- 没有第二套范围、魔法裁剪常量、重复坐标转换、跨层回读或临时视口 patch。
- 可以在父级 Git 中创建仅以 `agv-map-3d` 子目录为范围的 TASK-017 checkpoint，代码库可安全进入 TASK-018。

### 回退边界

回退 TASK-017 checkpoint 只移除有限地面、标准 fit 与动态裁剪能力；TASK-012 的 `contentBounds` 及 TASK-001～TASK-016 已交付的数据、几何和测试能力保持完整，不受父级仓库其他目录影响。
