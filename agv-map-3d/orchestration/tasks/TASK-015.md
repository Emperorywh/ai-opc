## 任务描述

### 可验证结果

项目具备带可追溯开源许可证的本地 Noto Sans SC Bold WOFF 字体、明确字形清单和构建期字形门禁；真实样本全部 4,810 个名称均通过逐 Unicode code point 校验。运行时只用该本地字体预加载全部去重名称字符，缺字或字体加载失败产生稳定错误且没有字体 fallback。

### 输入

- SPEC 第 2.5、3.2、4.2～4.3、11.1、14.1、15.1 节规定的字体格式、字符范围、直接依赖、预加载门禁和错误码。
- TASK-001 交付的精确 Troika 直接依赖及唯一依赖解析结果。
- TASK-002 交付的可信真实样本。
- TASK-011 交付的 4,810 个标签文本及稳定描述符。
- 执行前必须具备已批准且可复现的字体源或现成字体资产、对应许可证和来源身份；缺少任一项时，本 TASK 必须标记阻塞，后续 TASK 保持未执行。
- 用户确认的本地运行边界：本任务不交付 CSP 响应头或生产部署验证。

### 输出

- SPEC 指定的本地 Noto Sans SC Bold WOFF 字体资产、对应开源许可证、字形清单及可审计的字体来源记录。
- 构建期逐 code point 校验能力，覆盖 ASCII `U+0020–U+007E`、样本中文集合及全部真实标签文本。
- 运行时字体预加载边界：显式传入本地 WOFF URL 和全部去重名称字符，并只在成功回调后发出字体就绪信号。
- `FONT_GLYPH_MISSING` 与 `FONT_ASSET_FAILED` 的结构化错误结果，包含阶段、缺失 code point 或资产上下文。
- 覆盖真实样本字形、补充字符、字体加载成功/失败、缺字拒绝和无远程 fallback 的自动化测试。

### 实现约束

- 字体必须是 Troika 明确支持的本地 `.woff`，不得用 `.woff2`、远程字体、系统字体、Unicode CDN 或运行时字体替换。
- 字体来源、上游版本或提交身份、许可证和子集字符范围必须可审计；不得提交来源不明的二进制资产。
- 字形清单至少覆盖 ASCII 可打印字符和 `丝充制口抛桩点电碱站绒网门`，并以 Unicode code point 而非 UTF-16 单元检查每个标签文本。
- 构建期必须检查全部 4,810 个节点名和边名；任一缺字立即失败为 `FONT_GLYPH_MISSING`，不得等 Troika 联网补字或忽略该标签。
- 预加载必须显式使用本地字体 URL 和全部去重名称字符；只有成功回调可以产生字体就绪信号，失败统一映射为 `FONT_ASSET_FAILED`。
- 字体检查与预加载只消费标签文本契约，不得读取原始 JSON、重建标签描述符或维护第二套名称来源。
- 本任务不得创建全部或部分 Text 对象，不实现空间索引、可见集、billboard 或 R3F 标签图层。
- 按用户确认，本地运行不要求 CSP 响应头或生产部署集成；不得为此引入虚假生产服务器配置。
- 新增或修改的代码必须使用多行简体中文注释说明字体来源、字形门禁、预加载门槛与无 fallback 不变量；不得主动格式化无关代码。

### 验证方式

在 `C:\code\ai-opc\agv-map-3d` 执行：

```powershell
npm run lint
npm test -- --run
npm run build
```

- 正常路径：校验真实字体、许可证和字形清单，逐 code point 扫描 4,810 个名称，预期无缺字且实际中文集合与 SPEC 基线一致。
- 正常路径：通过可控字体加载端口验证本地 URL、去重字符集合和成功回调，预期只发出一次字体就绪信号，不创建 Text 对象、不访问远程 URL。
- 关键异常路径：从测试字形清单移除一个 ASCII 字符和一个中文字符，预期构建校验分别返回 `FONT_GLYPH_MISSING` 并准确报告 code point。
- 关键异常路径：模拟本地字体请求失败、解析失败或预加载回调失败，预期返回 `FONT_ASSET_FAILED`，不发出字体就绪信号且不切换系统/远程字体。
- 预期结果：三个命令退出码均为 0，真实资产、许可证、字符覆盖、预加载协议和失败门禁全部通过；命令不启动浏览器。

### 完成标准

- 本地字体资产来源与许可证可追溯，真实样本全部名称通过构建期字形门禁。
- 相关 lint、测试和构建全部通过，此前 TASK 的标签描述符、场景模型、worker 和资源适配行为未被破坏。
- 字体就绪和两类字体错误形成清晰、可供 application 层消费的显式契约。
- 没有远程/系统 fallback、Unicode CDN、WOFF2、原始 JSON 回读、提前创建 Text 或伪造生产部署配置。
- 当前状态可建立仅覆盖 `agv-map-3d` 子目录的独立 Git checkpoint，并安全进入 TASK-016。

### 回退边界

回退本 TASK 的 Git checkpoint 时，只移除本地字体资产、许可证/来源记录、字形门禁、预加载边界及其验证；TASK-001～TASK-014 已完成的数据、场景模型、worker 和 Three 资源能力保持不变。
