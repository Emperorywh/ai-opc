# config — 唯一视觉与性能常量表

## 职责
- 集中定义 SPEC 第 7 章的所有视觉常量、颜色、材质参数、层高、灯光与 renderOrder。
- 集中定义标签、相机与性能相关阈值。
- 后续落地文件固定为 `mapVisualConfig.ts`，作为全工程唯一常量入口。

## 依赖方向（SPEC 3.3）
- 允许依赖：本层自身。
- 允许的外部包：仅 Node 内置。
- 禁止依赖任何业务层、React、Three 或浏览器 API；常量是纯数据，被所有上层自由消费。

## 关键不变量
- 禁止组件内魔法数字或同义配置；任何视觉或性能调整必须先改本层再改消费方。
- 常量值（半径、宽度、层高、阈值等）以 SPEC 第 7、11、12 章为准，禁止在实现中自行取整或复制。
