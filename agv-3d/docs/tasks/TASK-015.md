# TASK-015 — 首帧后平滑淡入完整场景

## 需求

场景资源准备完成后必须先以不可见状态成功绘制首帧，再从加载界面平滑过渡到完整地图，避免空白、闪烁或半成品内容暴露。

## 验收标准

- 场景资源准备期间主画面保持透明，只有首帧成功绘制后才开始淡入。
- 淡入固定持续 500 ms，并将总进度从 98% 单调推进到 100%；完成后才进入就绪状态并移除加载界面。
- 系统启用“减少动态效果”时不强制播放完整动画，但仍保持首帧成功后再显示场景的顺序。
- 首帧或淡入前发生错误时直接进入统一错误界面，不短暂展示节点、路径或环境。
- 完整流程结束后页面可正常通过生产构建，且控制台不存在校验警告、被跳过记录或未处理的异步拒绝。
