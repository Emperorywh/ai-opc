# TASK-007 — 接通启动后的后台地图编译

## 需求

应用外壳首次呈现后必须立即在后台完成本地地图的下载、完整性校验、解析、严格校验、规范化和几何编译，并将完整编译结果交给场景准备流程，避免数据处理阻塞界面。

## 验收标准

- 应用外壳首次呈现后立即开始加载本地地图，不需要用户操作，也不将地图作为功能懒加载。
- 下载阶段按已读取字节数映射到总进度 0%～30%，并在解析前核对 6,516,343 bytes 和指定 SHA-256；任一指纹不符立即进入完整性错误。
- JSON 解析只报告离散的开始和完成；校验按已处理节点与边映射 30%～40%，节点编译按 1768 个节点映射 40%～55%，路径编译按 3045 条边映射 55%～90%。
- 成功结果包含完整节点、路径、场景边界和编译统计；大块二进制数据交接时不产生等量副本。
- 页面卸载或加载取消会中止尚未完成的下载和后台工作，后台执行单元最终归零。
- 重复挂载期间不会同时遗留多个有效后台加载，也不会出现未处理的异步拒绝。
