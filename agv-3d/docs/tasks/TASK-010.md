# TASK-010 — 展示有向路径与流动高亮

## 需求

地图必须用一份连续的路径展示完整的 3045 条有向边，并以稳定的流动高亮清楚表达每条边从源节点到目标节点的方向。

## 验收标准

- 基础路径为 `hsl(200, 85%, 55%)`，流动高亮为 `hsl(185, 100%, 75%)`，所有路径由一个展示批次和一种路径材质完成。
- 998 组双向车道中心间距为 0.36 m、无重叠闪烁；1049 条单向边位于自身中心线、无无意义侧移。
- 每条路径的高亮均从源节点流向目标节点，双向车道呈相反流向，修改 `isBackEdge` 不改变任何视觉流向。
- 流光重复距离为 2.0 m、速度为 0.4 m/s、周期为 5 s；长时间运行后相位仍保持有界且动画连续。
- 每帧只改变流光相位，不重建路径几何、材质或逐帧临时数据；页面不可见时暂停流光，恢复可见时不累计超大时间差。
- 路径不显示名称、连通性高亮、规划结果或其他业务交互。
