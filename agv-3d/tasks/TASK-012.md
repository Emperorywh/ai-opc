# TASK-012 — 构建深色沙盘环境

## 需求

地图必须呈现在统一的深色科技沙盘环境中，具备真实平面反射、距离衰减网格、适度雾效、环境照明和节点阴影，同时确保完整拓扑始终清晰可辨。

## 验收标准

- 场景背景为 `#05080F`，地面是深色不透明的真实平面反射，反射分辨率固定为 1024×1024 并带一次粗糙模糊，不随主画布分辨率增长。
- 独立网格的透明度随距地图中心的距离衰减；地面、网格、雾、阴影范围都由场景边界加统一环境边距推导，不出现写死范围导致的裁切。
- 线性雾在初始自动框选视角下不会遮蔽远端拓扑，节点类型和路径方向仍可辨识。
- 场景包含一个有阴影的方向光和一个低强度环境光，阴影分辨率固定为 2048×2048，只有节点投射阴影。
- 环境反射所需光照完全由本地生成，运行时不请求远程高动态范围图片。
- 反射、网格、雾和阴影可同时观察到，且不存在额外地面、重复反射或未来图层占位内容。
