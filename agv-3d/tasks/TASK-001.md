# TASK-001 — 建立 V76 地图数据契约

## 需求

应用必须随构建产物自托管规格指定的中环大地图 V76，并对资产指纹、数据结构、字段取值和拓扑引用执行严格校验。发现问题时必须一次性报告全部校验问题，不得跳过坏记录或产出不完整地图；契约外字段不得影响后续地图结果。

## 验收标准

- 构建产物使用的地图资产大小为 6,516,343 bytes，SHA-256 为 `DE2B1158FEFDC274673FB7F1813D8F193961359926B238B0CC334350A87FC567`，且加载过程不请求 CDN。

- 空或重复 ID、重复有向节点对、非法类型、非有限坐标或角度、缺失节点引用、零长度直线、控制点不完整的贝塞尔边、错误的节点角度约束以及非空区域数据都会导致校验失败。
- 校验失败时返回包含明确字段路径的全部问题，并且不返回可供展示的数据结果。
- 边的起终点保留边自身坐标；边端点与节点坐标的差异不报错，`isBackEdge` 的值也不改变校验结论。
