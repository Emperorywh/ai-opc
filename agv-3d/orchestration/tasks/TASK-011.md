## 任务描述

### 可验证结果

用户进入场景后获得完整的 45° 倾斜沙盘视角，并能平滑旋转、缩放和平移；初始框选、交互范围、resize 和有效 DPR 全部由最终渲染边界与固定性能预算决定，不会触发地图重新加载或静态几何重编译。

### 输入

- SPEC §6.3、§9、§11.1、§12、§13.1、§13.3、§16.2、§16.3 中的 framing、OrbitControls、resize 和像素预算要求。
- TASK-001 至 TASK-010 已交付的最终渲染边界、完整静态场景和受控帧循环。
- 任务开始时仓库内已有的相机数学、控制和 DPR 管理；必须审计极端窄屏、正尺寸下的精确 DPR 公式及配置集中性。

### 输出

- 固定 FOV 45°、near 0.1 m、far `max(1000 m, 包围球半径 × 10)` 的透视相机配置。
- 以渲染边界地面中心为 target、初始 polar angle 45°，通过八角点水平/垂直投影需求计算距离并保留 5% 安全区的初始 framing。
- 16:9 与 21:9 下完整容纳渲染边界的自动化证明；极端窄屏采用一致的安全策略，场景不会整体被裁掉或产生 NaN。
- 启用旋转、缩放、平移和阻尼的受控交互：polar angle 25°～70°、距离范围和 target 平移范围符合 SPEC。
- resize 时只更新 aspect、渲染尺寸和有效 DPR；对正有限 CSS 尺寸严格使用 `min(devicePixelRatio, sqrt(MAX_RENDER_PIXELS / (cssWidth × cssHeight)))`，主画布不超过 3840×2160 总像素预算。
- 覆盖相机基、八角点 framing、两种宽屏比例、极端窄屏、距离/平移边界、DPR 公式、resize 不重编译和监听释放的自动化验证。
- 初始框选、控制手感、不同窗口比例和 resize 的人工交互验收项。

### 实现约束

- framing 只能依赖 TASK-005 的最终渲染边界，不得使用节点 AABB、硬编码地图坐标或相机运行状态。
- FOV 固定，初始 framing 只调整相机距离；不得同时动态修改 FOV 和距离。
- 控件只负责相机行为，不承载点击、悬停、筛选或其他业务状态；卸载必须清理自身事件监听。
- 距离限制为 `minDistance = max(2 m, 半径 × 0.05)`、`maxDistance = 半径 × 4`；target 限制在水平边界外扩 20% 的区域。
- 对所有正有限尺寸必须严格遵守 SPEC 的 DPR 公式，不得用会突破总像素预算的下限覆盖计算结果；零尺寸或非有限的瞬态输入必须显式安全处理且不能触发新加载。
- resize 不得下载、解析、校验、编译或新建静态几何/材质；极端窄屏允许 letterbox，但不得以裁掉整个场景作为实现。
- 相机、性能和 framing 数值按职责集中，展示组件内不得散落重复常量。

### 验证方式

- 执行 `pnpm test`，预期相机 framing、控制范围、DPR、resize 不变量及 TASK-001 至 TASK-010 回归测试全部通过。
- 执行 `pnpm lint` 与 `pnpm build`，预期无类型、lint 或生产构建错误。
- 正常路径：以 V76 渲染边界计算 16:9 与 21:9 初始视角；预期八角点全部位于 5% 安全区，target、near、far、极角和距离均符合契约。
- 关键异常路径：输入极窄但正有限的容器、零尺寸瞬态、超高 devicePixelRatio 和连续 resize；预期不产生 NaN/Infinity，物理像素不超预算，场景未整体丢失且加载/编译调用次数不变。
- 交互路径：旋转到极角上下限、缩放到距离上下限、平移到外扩边界并卸载；预期参数被稳定限制，卸载后无残留监听。
- 人工验收：由用户在本地浏览器验证自动框选、旋转、缩放、平移、阻尼、16:9/21:9/极窄窗口和 resize；Coding Agent 不得自动启动浏览器。

### 完成标准

- 自动框选、受控交互、resize 与像素预算均可独立验证且不触发静态数据重处理。
- `pnpm test`、`pnpm lint`、`pnpm build` 全部通过，TASK-001 至 TASK-010 的行为没有被破坏。
- 不存在硬编码地图范围、重复 framing、突破预算的 DPR 下限、相机业务状态或 resize 资源重建。
- 与本任务相关的改动可形成单一独立 Git checkpoint，不混入环境、反射或后处理实现。
- 代码库处于一致、可运行、可验证状态，可以安全进入 TASK-012。

### 回退边界

回退本 TASK 的 Git checkpoint 只移除或还原自动框选、OrbitControls 约束、resize/DPR 管理和对应验证；TASK-001 至 TASK-010 的数据编译、加载体验、节点与路径展示保持完整。
