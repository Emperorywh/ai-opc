## 任务描述

### 可验证结果

真实海域呈现细微、连续、非规则扫描线式的动态水面；水面具有随视角和光照可感知的微波方向变化，透过半透明水体可辨认近岸浅、远海深的大陆架层次，同时不抢夺陆地地形和政治边界的视觉焦点。

### 输入

- TASK-004 完成后的真实海域覆盖边界。
- 当前海面颜色、透明度范围、统一渲染时钟、场景光照、雾和负高程地形。
- 已确认约束：运行时零外网，不下载法线贴图；海面透明度保持在既定合理范围内。

### 输出

- 与深色科技风一致的动态海面视觉配置与可测试输入契约。
- 微波变化作用于可信的表面明暗或法线语义，不再以高频规则亮度条带冒充水面。
- 海水颜色或透明表现能够体现水下地形深度关系，且地形仍是大陆架事实源。
- 动画继续使用统一帧循环，逐帧只更新必要的小型状态。

### 业务规则与状态不变量

- 海平面仍为统一 `0m`，水面视觉不得改变海陆分类。
- 海面动画暂停与恢复必须服从统一运行时生命周期。
- 大陆架层次来自真实负高程，不使用人工海岸阴影贴图伪造。
- 水面不能遮蔽十段线、岛礁点、沿海省界或低地陆地。

### 实现约束

- Coding Agent 必须先检查当前水面 shader、光照和透明排序，再自主选择低成本实现。
- 不冻结具体噪声、波浪或法线算法；禁止引入运行时网络纹理和独立动画时钟。
- 不得创建高分段水面几何或逐帧对象、大数组和材质。
- 视觉参数必须集中，不能散落到场景和 UI。
- 新增或修改的代码必须使用多行简体中文注释解释微波语义、透明混合、大陆架来源和性能边界；不得格式化无关代码。

### 验证方式

1. 执行 `pnpm test`，验证海面时间输入、透明度、暂停恢复和海域约束不变量。
2. 自动化证明水面层不会修改真实高程、海陆分类或地表色阶。
3. 执行 `pnpm lint` 与 `pnpm build`。
4. 人工执行 `pnpm dev` 后自行打开页面，持续观察和旋转相机，预期水面流动细微连续、无固定扫描线，近岸到远海深度层次可信。
5. 人工检查海岸、低地、十段线和岛礁，预期无遮挡、漏水、透明排序闪烁；不得自动启动浏览器。

### 完成标准

- 动态水面具有可信微波与大陆架表现，截图中的规则横向条带已消失。
- 海面保持低成本、离线、统一时钟和无逐帧大分配。
- 地形、边界、标签和政治要素无回归。
- 测试、lint、构建和人工视觉验收通过。

### Git checkpoint

可以创建只包含动态海面质感、视觉配置、测试和必要说明的独立 Git checkpoint；checkpoint 后代码库可安全进入 TASK-006。

### 回退边界

回退本 TASK 只移除水面质感增强，TASK-004 的海域覆盖边界与此前地形/深度修复仍然保留。
