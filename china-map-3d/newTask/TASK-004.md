## 任务描述

### 可验证结果

海面只影响真实海拔低于海平面的区域；所有 `h≥0` 的陆地片元不受海面颜色、透明度或波动影响。海岸线、低海拔平原和岛屿在任意合法相机与 `k` 下边界稳定，不再依赖深度缓冲偶然裁掉覆盖全图的海面。

### 输入

- TASK-001 至 TASK-003 完成后的统一高程、显示空间和深度策略。
- 真实米制海拔、海平面 `0m`、负高程大陆架及当前动态海面层。

### 输出

- 海域覆盖的单一语义契约，明确陆地、海平面与水下区域的判定规则。
- 海面渲染只读消费与地形相同的高程事实源，不维护第二份海陆 mask 或重复解码公式。
- 海岸临界区域具有确定、可测试的处理方式，不因纹理过滤、显示夸张或相机距离产生陆地漏水。
- 高程或海域判定不可用时显式失败，不回退成覆盖整张地图的透明平面。

### 业务规则与状态不变量

- 海陆分类只由真实海拔与统一海平面决定，不使用显示高度、颜色或行政区几何推断。
- `k` 变化不得改变海岸线或海域范围。
- 海面不得改写地形高程、色阶、边界或 hover 状态。
- 水下负高程必须保留并继续可见，不能简单裁掉全部水下地形。

### 实现约束

- Coding Agent 必须先检查现有海面与高程数据流，再自主决定海域约束在渲染适配层的内部表达。
- 禁止复制 4096² 高程数据、引入在线海陆底图或在组件中维护手工海岸多边形。
- 不得通过整体抬升陆地或下沉海面规避语义裁剪。
- 本 TASK 只闭合海域覆盖，不承担后续水面质感调优。
- 新增或修改的代码必须使用多行简体中文注释解释海陆判定、海岸临界值和单一事实源；不得格式化无关代码。

### 验证方式

1. 执行 `pnpm test`，使用负高程、`0m`、低正高程、岛屿和海岸插值样本验证海面覆盖结果。
2. 自动化切换全部合法 `k` 与代表性相机状态，预期海陆覆盖集合完全不变。
3. 自动化模拟高程不可用或编码不匹配，预期海面层明确失败而非全图 fallback。
4. 执行 `pnpm lint` 与 `pnpm build`。
5. 人工观察东部平原、海南岛、台湾岛和沿海岛屿，预期陆地无水面条纹，海岸连续稳定；不得自动启动浏览器。

### 完成标准

- 海面只覆盖真实海域，陆地漏水和海岸闪烁已由自动化及人工验收排除。
- 海陆判定与地形高程保持单一事实源。
- 没有重复 mask、视觉偏移、运行时网络或失败 fallback。
- 测试、lint、构建全部通过。

### Git checkpoint

可以创建只包含海域语义边界、异常处理和相关测试的独立 Git checkpoint；checkpoint 后代码库可安全进入 TASK-005。

### 回退边界

回退本 TASK 恢复此前海面覆盖行为，但保留 TASK-001 至 TASK-003 的高程、地形尺度和深度修复。
