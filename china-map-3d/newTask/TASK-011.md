---

## 任务描述

### 可验证结果

默认全图画面首先读到真实地势体积与高程色阶，其次读到省级边界和十段线，最后读到省名、省会光点和岛礁标注；34 个省名在允许相机范围内清楚可读，边界不压过地形，标签遮挡、hover 放大和入场透明度具有确定优先级且无闪烁。

### 输入

- TASK-001 至 TASK-010 完成后的完整、稳定场景。
- 当前地表色阶、光照、雾、省界、政治线点、标签、遮挡、hover 和入场状态。
- 深色科技风、纯地理展示、固定标签锚点和不隐藏政治必需要素的全局决策。

### 输出

- 集中、可审计的主图视觉层级规则，明确地形、海面、边界、政治要素、标签和焦点态的相对权重。
- 默认、遮挡、hover、入场和恢复后的标签样式能够确定性合成，不由多个状态互相覆盖。
- 34 个省名、港澳台、省会光点及必需岛礁名称在1080p和4K目标构图下可读。
- 密集区域若需调整，只允许使用可审计的领域锚点或统一视觉规则，不在组件内写局部偏移。

### 业务规则与状态不变量

- 地形是视觉主体，边界是辅助阅读层，标签和光点不能替代地貌表现。
- 正常态边界必须可见但不成为全屏最高对比度主体；hover 省份才获得显著焦点。
- 标签被前方地形遮挡时淡化，焦点态提升可读性，但不能永久穿透山体。
- 不得隐藏任何省、十段线、必需岛礁或合规名称来减少拥挤。

### 实现约束

- Coding Agent 必须先基于实际运行画面检查亮度、字号、空间尺度和状态合成，再自主调整视觉参数与职责边界。
- 视觉配置必须集中；禁止为单省、单标签、单相机角度编写样式补丁。
- 不引入业务颜色、业务 tooltip、卫星纹理、天空盒、实时标签碰撞或移动端布局。
- 不得以关闭深度测试让文字永久穿透地形。
- 新增或修改的代码必须使用多行简体中文注释解释视觉层级、状态合成和可读性边界；不得格式化无关代码。

### 验证方式

1. 执行 `pnpm test`，验证正常/遮挡/hover/入场状态的颜色、线宽、缩放、透明度和优先级合成。
2. 自动化验证 34 个省名、34 个省会光点、港澳台和必需岛礁标注全部存在且没有被视觉优化删除。
3. 执行 `pnpm lint` 与 `pnpm build`。
4. 人工在默认视角、最近/最远缩放、低俯角和密集区域观察，预期先读地貌、再读边界、最后读标签，文字清楚且无闪烁。
5. 人工快速 hover 多省并旋转相机，预期焦点、遮挡和恢复一致；不得自动启动浏览器。

### 完成标准

- 主图达到“真实地貌为主角”的明确视觉层级。
- 省名、政治标注和 hover 在目标大屏上清楚、稳定、完整。
- 不再出现边界压过地形、标签点状不可读或状态互相覆盖。
- 测试、lint、构建和人工视觉验收通过。

### Git checkpoint

可以创建只包含主图视觉层级、标签状态合成、必要配置和测试的独立 Git checkpoint；checkpoint 后代码库可安全进入 TASK-012。

### 回退边界

回退本 TASK 只移除主图视觉层级调优，不回退地形尺度、海面、状态闭环、政治边界、hover 或资源生命周期修复。
