## 任务描述

### 可验证结果

1080p和4K大屏中，海拔图例、南海诸岛附图、加载/恢复反馈和合规角标清楚可读、分区明确且不遮挡主图核心；生产页面不再显示垂直夸张按钮、网格分段等开发调试控件，整体达到独立地理展示大屏而非调试工具的交付观感。

### 输入

- TASK-011 完成后的主图视觉层级。
- 当前海拔图例、南海附图、合规来源/免责声明、加载和运行时诊断 overlay。
- 已确认的页面边界：无业务仪表盘、无移动端适配、无公开审图状态、只保留必要外围 UI。

### 输出

- 1080p与4K目标尺寸下稳定的 overlay 分区与可读性规则。
- 南海附图中的十段线、台湾东侧段、必需岛礁点和名称均可辨认，构图具有足够地理上下文且继续复用主图事实源。
- 合规角标完整显示审图号占位、来源、非官方状态和不得正式发布免责声明，长文本不产生破碎换行或信息混淆。
- 海拔图例与地表色阶继续共享唯一配置，刻度完整、层级清楚。
- 生产构建不呈现开发调试控件；如保留开发诊断能力，其边界必须显式且不能进入生产 UI。

### 业务规则与状态不变量

- 页面外围只允许图例、附图、加载/恢复反馈和合规角标。
- 南海附图和主图不得维护两套政治坐标、名称或投影公式。
- 审图号占位不得伪装成已获批号码，完整免责声明不得省略或弱化到不可读。
- UI 调整不能遮挡新疆、西藏、东部沿海、台湾或主图南海政治要素。

### 实现约束

- Coding Agent 必须先检查实际1080p/4K截图和文本换行，再自主决定布局、排版和视觉细节。
- 不冻结具体 CSS 结构、SVG 组织或组件拆分；DOM overlay 不得反向控制 3D 场景。
- 不新增底部业务栏、标题大屏框架、移动端断点、装饰性图表或在线底图。
- 不得通过缩小文字到不可读尺寸换取不重叠。
- 新增或修改的代码必须使用多行简体中文注释解释分区、色阶复用、附图事实源和发布限制；不得格式化无关代码。

### 验证方式

1. 执行 `pnpm test`，验证图例色阶单一事实源、六个关键刻度、附图必需政治要素、三类来源和完整免责声明。
2. 自动化验证生产 UI 不包含垂直夸张、网格分段或其他开发调试控件。
3. 自动化或布局测试验证1080p/4K目标尺寸下四类 overlay 的边界不相互覆盖且不进入主图核心保留区。
4. 执行全部相关资产校验、`pnpm lint` 与 `pnpm build`。
5. 人工分别以1080p和4K打开页面，确认附图、图例和角标文字可读、布局克制、加载/恢复反馈正确；不得自动启动浏览器或公开部署。

### 完成标准

- 外围 UI 在两种目标大屏尺寸下可读、完整、不重叠且不遮挡主图。
- 南海附图达到可核查的地理附图观感，不再只是稀疏且难读的线点框。
- 生产页面已移除调试工具观感，合规限制仍完整明确。
- 测试、资产校验、lint、构建和人工 UI 验收通过。

### Git checkpoint

可以创建只包含外围 UI、南海附图呈现、生产调试边界和相关测试的独立 Git checkpoint；checkpoint 后代码库可安全进入 TASK-013。

### 回退边界

回退本 TASK 只恢复此前 overlay 样式与生产调试控件状态，不回退完整主图、政治事实或生命周期修复。
