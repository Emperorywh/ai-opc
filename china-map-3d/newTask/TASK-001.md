---

## 任务描述

### 可验证结果

完整页面只建立一份可查询的 CPU 高程表示；省界、政治要素、标签、遮挡、海陆判断与后续交互共享同一真实米制高程事实源。重复挂载、垂直夸张切换和多消费者并存不会重复解码 16 位栅格，也不会遗留无法释放的高程引用。

### 输入

- 当前 16 位离线高程资产、元数据契约和 GPU 高程纹理加载结果。
- 当前运行时高程查询、边界准备、政治要素准备、标签准备和遮挡查询能力。
- 已确认的全局规则：CPU 与 GPU 可以使用不同表示，但必须共享同一编码、元数据和真实米制语义；运行时禁止外网 fallback。

### 输出

- 明确且可审计的运行时高程资源所有权契约，描述创建、共享、只读消费和释放边界。
- 单一 CPU 高程查询实例供所有领域消费者复用，消费者不得自行创建或解码第二份高程表示。
- 明确区分 CPU 高程生命周期与 GPU 纹理生命周期；任一消费者卸载不得提前破坏其他消费者仍在使用的资源。
- 自动化计数或等价证据，证明同一页面生命周期内只发生一次 CPU 解码和一次查询资源创建。

### 业务规则与状态不变量

- 查询结果始终是未应用垂直显示夸张的真实米制海拔。
- 合法负高程、海平面和正高程必须可区分；失败不得伪装为 `0m`。
- 同一高程资产与元数据只能对应一个活动 CPU 查询所有者。
- 资源释放后必须明确不可查询，不得保留隐式全局引用。

### 实现约束

- Coding Agent 必须先检查任务执行时的实际代码，再自主决定资源装配位置、模块结构和生命周期表达方式。
- 资产层和高程领域层不得依赖 React、Three.js 场景对象、hover 或 DOM UI；渲染和交互只能单向消费。
- 不得通过全局可变单例、重复包装、复制大数组或兼容旧实现完成共享。
- 不修改高程编码、投影、色阶或可见效果；必要重构仅服务唯一所有权结果。
- 新增或修改的代码必须使用多行简体中文注释解释资源所有权、共享边界与释放不变量；不得格式化无关代码。

### 验证方式

1. 执行 `pnpm test`，创建省界、政治要素、标签和遮挡等多个消费者，预期底层 16 位数据只解码一次且查询结果一致。
2. 自动化重复挂载、卸载及 StrictMode 重挂载，预期活动查询实例数和大数组数量稳定，最后一个所有者释放后资源可回收。
3. 自动化切换 `k=1.5/2.0/3.0`，预期不重新解码高程，真实米制查询值保持不变。
4. 执行 `pnpm lint` 与 `pnpm build`，预期完整页面通过且无行为回归。

### 完成标准

- 单一 CPU 高程查询所有权已由代码结构和自动化证明。
- 全部现有高程消费者共享同一实例，正常、异常和释放路径均有验证。
- 没有重复解码、重复大数组、隐式全局状态或平地 fallback。
- 测试、lint 和构建全部通过，当前页面仍可运行。

### Git checkpoint

可以创建只包含高程资源所有权重构、相关测试和必要说明的独立 Git checkpoint；checkpoint 后代码库可安全进入 TASK-002。

### 回退边界

回退本 TASK 只移除统一高程资源所有权及其验证，不修改高程资产、投影、地形 shader、边界数据或可见 UI。
