## 1. 三层验证边界（不得互相替代）

| 层次 | 负责对象 | 能证明什么 | 不能证明什么 |
|---|---|---|---|
| **自动化完整性检查**（`political-deep.ts`） | 机器 | SPEC §6 点名必备项**在**（10 段含台湾东侧段、钓鱼岛/赤尾屿/曾母暗沙、藏南/阿克赛钦）、坐标落中国主图、来源标记非官方审图 | 南海诸岛完整岛礁名录已穷尽；九段线/争议区几何顶点与国标逐点重合；数据已过官方审图 |
| **人工地图核对**（本记录） | 核对人 | 自动化清单的点名项与当前公开标准地图**逐项一致**；完整岛礁名录闭包；几何顶点级合理性 | 取得自然资源主管部门审图号；法律层面的边界主张效力 |
| **官方审图**（发布前） | 自然资源主管部门 | 取得具名审图号，公开发布合法 | —（审图结果是公开发布的前置条件，非本 TASK 可自证） |

三层缺一不可：自动化清单不能替代人工核对，人工核对不能替代正式审图。本 TASK 只交付前两层的能力
与模板，**不产生虚假合规结论**。

## 3. 可追溯来源调查记录（TASK-006 实现约束：不得凭视觉猜测或复制来源不明坐标）

实现约束要求：在判定「无法获得可追溯核对基准」之前，必须先用可用工具实际调查可追溯来源。
本节记录已调查的可追溯候选与差异点，作为收窄阻塞的依据。下方 `调查状态` 标记为
`已调查` / `待调查`；只有全部候选调查完毕且均不可用，才可就该项返回 blocked。

### 3.1 自然资源部标准地图服务（bzdt.ch.mnr.gov.cn）

- **性质**：中国官方标准地图服务，提供带具名审图号（如 GS(202x)xxxx 号）的可下载标准地图
  （SVG / PNG / JPG），是中国地图边界的权威依据。
- **调查状态**：已调查（2026-07-19）。该站点为权威来源，但其下载产物以**可视化地图**（SVG / PNG）为主，
  不是结构化矢量坐标数据集；从中数字化九段线顶点属「凭视觉猜测」，违反 TASK-006 实现约束
  （「不得自行凭视觉猜测或复制来源不明坐标」）。站点常需在可联网环境交互访问（验证码 / 地区限制），
  自动 WebFetch 不足以提取可追溯的结构化坐标。
- **结论**：作为**人工核对的基准地图**（核对人肉眼对照）完全合格；作为**自动化可追溯坐标源**不合格
  （无可机器消费的结构化坐标 + 视觉数字化被实现约束禁止）。故 §2.1 / §2.2 几何顶点项保持 pending，
  待人工核对阶段以审图号作为基准标识填入。

### 3.2 Natural Earth（公共领域、版本化）

- **性质**：公共领域（public domain）、版本化、可追溯的全球地理数据集（naturalearthdata.com），
  非「来源不明」。
- **调查状态**：已调查（2026-07-19，Natural Earth 1:10m Cultural Vectors 官方说明）。Natural Earth
  **默认按 de facto（实际控制）边界**呈现，而非 de jure（法理主张）边界；中国的九段线 / 十段线属
  de jure 主张线，**不在 Natural Earth 默认数据集中**。Natural Earth 对部分争议区提供可选的
  point-of-view (POV) 变体，但其画法基于国际通用视角，**与中国国标十段画法存在差异**，不可作为
  国标画法唯一依据。
- **结论**：可作为交叉核对参考（稳定无争议点位如钓鱼岛 / 赤尾屿 / 曾母暗沙的存在性与数量级坐标），
  但九段线几何走向与争议区画法**不可**以 Natural Earth 为准——差异点须以自然资源部标准地图为准。
- **稳定无争议点位**（钓鱼岛 ≈ 25.75°N/123.46°E、赤尾屿 ≈ 25.92°N/124.55°E、曾母暗沙 ≈ 3.58°N/112.30°E）
  在公开标准地图衍生数据与权威地名录中长期一致，可作为「点位存在性 + 数量级」的可追溯基准；
  生产资产交付时须在 basis 字段逐点登记具体来源（地名录 / 标准地图版本）。

### 3.3 公开标准地图衍生坐标 / 权威地名录

- **性质**：钓鱼岛（≈ 25.75°N, 123.46°E）、赤尾屿（≈ 25.92°N, 124.55°E）、曾母暗沙
  （≈ 3.58°N, 112.30°E）等稳定点位的坐标在公开标准地图衍生数据与权威地名录中长期一致，
  可作为「点位存在性 + 数量级」的可追溯基准（basis 登记具体来源）。
- **调查状态**：部分已落地（增强夹具已含上述 representative 坐标），但生产资产的 basis 字段
  仍需逐点登记可追溯来源（具体地名录 / 标准地图版本），不得停留在「representative 坐标」。

### 3.4 第三方九段线数据集（ArcGIS / GeoDOI 等）

- **调查发现**：Web 检索确认存在可 fetch 的九段线坐标数据集（如 ArcGIS Online 上的 Nine Dash Line
  GeoJSON linestring、geodoi.ac.cn 的「南中国海 U 形线与九段线数据集」）。这些坐标**可以获取**，
  不是「技术上不可得」。
- **为何仍属「来源不明」**：这些数据集为第三方 / 学术衍生产物（非自然资源部标准地图服务官方发布），
  其与国标十段画法的逐点一致性**无法自动证明**——TASK-006 实现约束要求「不得复制来源不明坐标」，
  指的正是「未经国标核对的第三方坐标」，而非「坐标技术上无法下载」。直接复制这些坐标将无法满足
  「可追溯核对基准」要求（基准须为自然资源部标准地图或其可追溯衍生）。
- **结论**：这些数据集可作为人工核对阶段的**交叉参考**（核对人肉眼比对第三方坐标与标准地图的差异），
  但**不可直接作为生产资产坐标**。这把阻塞精确收窄为：「需要具名核对人以自然资源部标准地图为基准，
  逐段 / 逐点核对并签字」，而非「坐标无法获取」。

## 4. 阻塞收窄结论

基于上述调查框架，TASK-006 的阻塞**收窄**为以下**真正无法自得**的项（其余可自动化管线已就位）：

1. **九段线各段几何顶点的可追溯数字化**：需自然资源部标准地图 SVG 或等价可追溯矢量基准
   （§3.1 调查后判定）。representative 夹具坐标不可作为生产资产。
2. **争议区边界（藏南 / 阿克赛钦）几何的可追溯国标画法**：同上。
3. **完整南海诸岛岛礁名录闭包**：须人工对照公开标准地图确立（自动化只覆盖 SPEC §6 点名少数项）。
4. **人工核对人身份 + 具名基准标识**：本记录 §2 各表的「核对人 / 日期 / 基准标识」字段待真人填写。
5. **官方审图号**：发布前由自然资源主管部门审图流程取得，非本 TASK 可自证。

在上述未决项闭环前，TASK-006 的 `political` scope 暂指向增强夹具，生产可追溯政治资产未交付；
直接消费政治补充数据的渲染 TASK（TASK-015 主图十段线 / 岛礁点位、TASK-019 南海 2D 附图）暂停，
通用领域能力 TASK（TASK-007 投影 / TASK-008 高程查询 / TASK-009 GPU 地形等）不阻塞、可并行推进。
