## 任务描述

### 可验证结果

页面在不遮挡主图核心区域的前提下显示与地表一一对应的海拔色阶图例、审图号占位、数据源署名和非官方审图免责声明；用户能正确读图，同时明确知道当前页面不得用于正式公开发布。

### 输入

- SPEC §3.1、§6、§8、§9、§12.2、§12.11、§13。
- TASK-001 的来源声明契约。
- TASK-003、TASK-004、TASK-006 的 DEM、边界和项目补充数据来源记录。
- TASK-010 的唯一海拔色阶配置。
- TASK-019 的右下 2D 附图布局。

### 输出

- 贴边的竖向或横向海拔色阶图例，直接消费地表唯一色阶配置，并标注 0、1000、2000、3500、5000、8848m 关键刻度。
- 低调角标形式的审图号占位，示例状态明确为 `GS(202x)xxxx号` 或等价未填写标识，不得伪装成已获批号码。
- 低调角标形式的数据源署名，覆盖 Copernicus DEM GLO-30、DataV.GeoAtlas 及项目补充十段线/岛礁数据。
- 明确免责声明：“本图边界数据为非官方审图数据，仅供内部展示，不得作为正式出版/发布用途”，直至外部审图流程提供真实审图号。
- 这些 overlay 与 3D 场景、南海附图布局分区清晰；页面除图例、附图、加载反馈和合规角标外不增加其他外围 UI。

### 实现约束

- 图例不得复制色阶断点和颜色，必须从 TASK-010 的单一事实源派生。
- 合规角标只消费来源/审图状态，不得反向控制资产、场景或交互。
- 不得以占位审图号暗示已经审图，不得删除“非官方、仅内部展示、不得正式发布”的限制。
- 不做完整底部栏、业务仪表盘、移动端响应布局或额外装饰面板。
- 位置和视觉样式可由 Coding Agent 在深色科技风内调试，但必须同时避让主图核心和右下附图。
- 新增或修改的代码必须用多行简体中文注释解释色阶复用、审图状态和发布限制；不得主动格式化无关代码。

### 验证方式

1. 执行 `pnpm test`，预期图例颜色和断点与地表配置引用同一事实源，六个关键刻度完整且顺序正确。
2. 自动化验证 DEM、边界、项目补充数据三类署名、审图号占位和完整免责声明均存在；缺少任一项时失败。
3. 执行 `pnpm verify:assets -- --scope terrain`、`pnpm verify:assets -- --scope provinces`、`pnpm verify:assets -- --scope political`、`pnpm lint` 和 `pnpm build`，预期全部通过。
4. 人工执行 `pnpm dev` 后自行打开页面；预期图例与地表颜色一致，文字可读，角标低调且不遮挡主图核心或南海附图。
5. 人工确认页面仍明确处于“未取得审图号、仅内部展示”状态；不得自动启动浏览器，也不得公开部署。

### 完成标准

- 海拔图例、审图号占位、三类数据源署名和免责声明全部呈现。
- 图例与 shader 色阶单一事实源可由自动化证明。
- 全部资产校验、构建、lint、测试和人工验收通过，入场及主图行为无回归。
- 没有重复色阶、虚假审图号、发布限制缺失或额外业务 UI。
- 可以创建只包含图例与合规角标结果的 Git checkpoint，代码库可安全进入 TASK-022。

### 回退边界

回退本 TASK 只会移除海拔图例和合规角标；3D 主图、南海附图和数据来源记录仍保留，但页面重新变为缺少合规提示、禁止进入任何发布流程的状态。
