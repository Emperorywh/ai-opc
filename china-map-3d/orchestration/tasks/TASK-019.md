## 任务描述

### 可验证结果

页面右下角存在独立于 3D 场景的 2D 南海诸岛矩形附图，完整显示十段线、南海主要岛礁点位和规范名称；附图与主图使用同一地理事实源和投影语义。

### 输入

- SPEC §2“南海诸岛”、§3.3、§3.8、§5.3–§5.4、§6、§8、§12.3。
- TASK-006 的完整政治边界补充数据和核对清单。
- TASK-007 的统一墨卡托投影与附图子范围映射。
- TASK-016 的规范中文字符串与字体能力。
- TASK-018 完成后的主图，不要求附图参与省级 hover。

### 输出

- 右下角 DOM overlay 形式的 2D 矩形附图，使用 SVG 或 Canvas 2D 等实现；不得作为 3D mesh 嵌入场景。
- 附图完整绘制十段线、南海主要岛礁点位及名称，包含台湾东侧段，构图符合南海附图的合规惯例。
- 附图坐标由与主图相同的墨卡托结果映射到独立 2D 子范围，不维护重复坐标数据。
- 附图在大屏目标尺寸下可读，不遮挡主图核心区域，并能与后续合规角标明确分区。
- 自动化测试逐项核对附图消费的政治要素和投影结果，人工对照 TASK-006 基准完成视觉核查。

### 实现约束

- 主图和附图必须共享 TASK-006 数据及 TASK-007 投影；禁止复制一份专用十段线、岛礁或名称数组。
- 附图属于 DOM overlay/UI 适配层，不得反向修改 3D 相机、地形、hover 或领域资产。
- 不在附图中引入业务数据、下钻、点击或实时网络底图。
- 本 TASK 不声称获得审图号，仍只能内部展示；正式发布由 TASK-021 的合规状态和外部审图流程约束。
- 具体 SVG/Canvas 选择、内部元素组织和样式实现由 Coding Agent 决定。
- 新增或修改的代码必须用多行简体中文注释解释数据复用、子范围映射和非审图限制；不得主动格式化无关代码。

### 验证方式

1. 执行 `pnpm test`，预期附图模型包含完整十段线、必需岛礁点和规范名称，同一坐标与主图投影结果一致。
2. 删除测试输入中的台湾东侧段或任一必需岛礁名称，预期附图准备明确失败。
3. 执行 `pnpm verify:assets -- --scope political`、`pnpm lint` 和 `pnpm build`，预期全部通过。
4. 人工执行 `pnpm dev` 后自行打开页面；预期右下附图矩形清晰、要素完整、文字可读且不遮挡主图核心地形。
5. 人工对照 TASK-006 核对清单逐项验收附图；不得自动启动浏览器，也不得公开部署。

### 完成标准

- 2D 南海附图的十段线、岛礁点和名称完整，并通过自动化与人工核对。
- 主图与附图数据、投影单一事实源得到证明。
- 资产校验、构建、lint、测试和人工验收通过，主图交互无回归。
- 没有重复坐标、运行时底图请求、3D/DOM 跨层耦合或虚假审图状态。
- 可以创建只包含 2D 南海附图结果的 Git checkpoint，代码库可安全进入 TASK-020。

### 回退边界

回退本 TASK 只会移除右下 2D 附图；主 3D 图的省界、十段线、岛礁、标签和 hover 能力全部保持不变。
