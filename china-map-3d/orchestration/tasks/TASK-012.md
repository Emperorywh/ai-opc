## 任务描述

### 可验证结果

3D 地形具备深蓝黑大屏背景、西北高位方向主光和低强度环境补光，背光面仍可辨认且地势方向清楚；地图远缘与背景自然衔接，不依赖天空盒或高成本地形阴影。

### 输入

- SPEC §2“氛围”、§3.1、§3.4、§12.1–§12.2。
- TASK-009 的地形网格。
- TASK-010 的法线明暗与深色分层设色。
- TASK-011 的默认观察方向。

### 输出

- 深蓝黑纯色或竖向渐变背景，适配独立大屏并与地表色阶保持足够对比。
- 从西北偏高方位照射的单盏方向主光和低强度半球环境光，突出青藏至东海的地势梯度。
- 如实际观感需要，可加入极轻微指数雾；启用时须确保不吞没边界、标签和南海要素的未来可读性。
- 地形不投递高分辨率阴影贴图；任何可选阴影能力必须保持局部、低成本且不成为本 TASK 完成条件。
- 视觉参数集中管理，场景装配不复制色阶或相机领域逻辑。

### 实现约束

- 不引入天空盒、卫星影像、人工阴影贴图或与纯地理展示无关的装饰资产。
- 光照/背景层只能依赖场景视觉配置，不得读取行政区、地点或 hover 状态。
- 雾是可选视觉决策；若不启用，地图远缘仍须通过背景和构图自然衔接。
- 不以过强环境光冲淡高程色阶，不以过浓雾遮蔽南海或边缘行政区。
- 具体颜色和强度可在 SPEC 基线附近调试，但必须由人工验收证明目标结果。
- 新增或修改的代码必须用多行简体中文注释解释光向、阴影预算和雾的取舍；不得主动格式化无关代码。

### 验证方式

1. 执行 `pnpm test`，预期场景视觉配置满足主光方向、单主光、环境光存在和地形阴影关闭等不变量。
2. 执行 `pnpm lint` 与 `pnpm build`，预期场景装配通过且不引入外部纹理请求。
3. 人工执行 `pnpm dev` 后自行打开页面；预期西部高地受光层次明显、背光山体不死黑、东部平原仍能辨认，背景无天空盒接缝。
4. 人工从允许的相机极角观察地图边缘；预期背景衔接自然，若启用雾则南海和远缘地形仍可读。
5. 检查渲染配置，预期不存在地形高分辨率阴影图；不得自动启动浏览器。

### 完成标准

- 深色背景、主光、环境补光及可选轻雾共同达到可观察的地势层次。
- 自动化不变量和人工视觉验收均通过。
- 构建、lint、测试通过，地形色阶和相机行为无回归。
- 没有天空盒、人工阴影贴图、外部纹理依赖或跨层视觉逻辑。
- 可以创建只包含场景氛围结果的 Git checkpoint，代码库可安全进入 TASK-013。

### 回退边界

回退本 TASK 只会移除深色氛围装配及相关配置；GPU 地形、分层设色和相机探索仍然可运行。
