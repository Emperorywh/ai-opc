## 任务描述

### 可验证结果

3D 主图在真实地理位置呈现南海十段线及必需岛礁/附属岛屿点位，十段线与省界视觉可区分，台湾东侧线段和 SPEC 点名要素均不会因主图范围或海面遮挡而丢失。

### 输入

- SPEC §2“政治边界/南海诸岛”、§3.8、§5.3、§6、§8、§12.3。
- TASK-006 已通过人工核对和完整性校验的政治边界补充资产。
- TASK-007 的统一投影。
- TASK-008 的高程/海平面查询语义。
- TASK-013 的海面与 TASK-014 的省界视觉基线。

### 输出

- 十段线作为独立地理线要素在主图真实位置完整呈现，包含台湾东侧段，并以比省界更明确的发光虚线或等价样式区分。
- 南海主要岛礁、钓鱼岛、赤尾屿等必需点位在真实位置有可见标记；规范名称由 TASK-016 的统一标签系统呈现。
- 线和点的高度由共享高程/海平面语义确定，既不被海面完全吞没，也不使用与地图脱节的固定世界坐标。
- 渲染只消费 TASK-006 的共享事实源，后续 2D 附图复用相同数据。
- 自动化测试逐项关联 SPEC §6 清单并证明主图范围包含所有必要要素。

### 实现约束

- 不得复制、手改或在组件内补写十段线/岛礁坐标；唯一事实源来自 TASK-006。
- 省界与政治补充要素可有不同视觉样式，但必须共享投影、单位和数据生命周期。
- 本 TASK 不宣称取得审图号；只能在内部展示状态下验收，正式发布仍被 TASK-006 的待审图状态禁止。
- 不把十段线合并为不可核查的单条连续折线，不得遗漏台湾东侧段。
- 不加入 click、下钻或业务数据交互。
- 新增或修改的代码必须用多行简体中文注释解释十段结构、海平面贴合和非官方审图限制；不得主动格式化无关代码。

### 验证方式

1. 执行 `pnpm test`，预期十个线段和全部必需点位都被主图渲染模型消费，且投影结果位于主图范围内。
2. 在测试输入中删除台湾东侧段或一个必需附属岛屿，预期渲染准备失败，不能静默显示残缺地图。
3. 执行 `pnpm verify:assets -- --scope political`、`pnpm lint` 和 `pnpm build`，预期政治资产红线与构建均通过。
4. 人工执行 `pnpm dev` 后自行打开页面；预期十段线完整、与省界可区分，岛礁/附属岛屿标记可见且位置不受相机旋转破坏。
5. 人工逐项核对 TASK-006 清单中的主图线/点要素；不得自动启动浏览器，也不得进行公开部署。

### 完成标准

- 主图十段线和必需岛礁/附属岛屿点位全部可见并通过清单核对。
- 缺段/缺点异常路径能阻断渲染准备。
- 资产校验、构建、lint、测试和人工验收通过，此前省界与海面无回归。
- 没有坐标复制、临时补点、静默残缺或虚假审图状态。
- 可以创建只包含主图政治补充线/点呈现的 Git checkpoint，代码库可安全进入 TASK-016。

### 回退边界

回退本 TASK 只会移除主图十段线和岛礁/附属岛屿点位渲染；TASK-006 的完整政治数据与核对记录、TASK-014 的 34 省边界均保持不变。
