## 任务描述

### 可验证结果

主图完整呈现 34 个始终面向相机的省名标签、34 个位置正确的省级行政中心光点，以及政治边界清单要求的岛礁名称；中文字体只包含实际所需字符且运行时离线可用。

### 输入

- SPEC §2“标签/标签内容”、§3.7、§5.5、§6、§7.2、§7.5、§10、§12.4、§13。
- TASK-005 的省名锚点、省级行政中心和最终地点字符串集合。
- TASK-006 的岛礁规范名称。
- TASK-007 的统一投影与 TASK-008 的高程查询。
- TASK-015 的主图岛礁点位。
- 已确认使用 drei Billboard/Text 或其 troika 文本能力。

### 输出

- 34 个省名 Billboard 标签，固定在可审计锚点上方并始终面向相机。
- 34 个省级行政中心发光光点，可选细光柱；默认画面至少保证“省名 + 省会光点”，省会名称仍保存在领域目录中。
- 南海诸岛、钓鱼岛、赤尾屿等政治完整性清单要求的规范名称标签，与对应点位稳定关联。
- 一份从实际省名、省会名和附图/岛礁文字确定性生成的 CJK 字符集合及离线字体子集；不得打包完整 CJK 字体。
- 标签、地点光点和字体加载错误都有明确状态，不因单个字符串缺字而静默显示空白或 fallback 网络字体。

### 实现约束

- 标签和光点视图只能消费地点/政治领域数据、投影和高程结果，不得自行维护经纬度或中文名称副本。
- 标签使用固定锚点，不实现实时碰撞推开；京津沪港澳等密集区域可使用数据层已有的可审计锚点校正。
- 字体子集必须覆盖全部实际字符串并离线加载，不得依赖系统字体偶然存在、在线字体或完整思源字体包。
- 省会名可根据实际拥挤情况以小字或非业务 tooltip 呈现，但这不是本 TASK 的强制默认可见结果；不得引入业务数据 tooltip。
- 地形遮挡透明度处理由 TASK-017 交付，hover 放大置顶由 TASK-018 交付，不在本 TASK 复制状态逻辑。
- 新增或修改的代码必须用多行简体中文注释解释锚点、字体子集、文本离线加载和标签职责边界；不得主动格式化无关代码。

### 验证方式

1. 执行 `pnpm test`，预期 34 个行政区各产生一个省名标签和一个行政中心光点，岛礁名称全部稳定关联。
2. 自动化验证字体字符集合覆盖所有最终字符串，删除任一必需汉字或提供损坏字体时应明确失败。
3. 执行 `pnpm verify:assets -- --scope places`、`pnpm verify:assets -- --scope political`、`pnpm lint` 和 `pnpm build`，预期全部通过且无在线字体请求。
4. 人工执行 `pnpm dev` 后自行打开页面并旋转相机；预期省名和岛礁文字始终面向相机，省会光点位置随地形正确，港澳台不缺失。
5. 人工检查网络断开状态，预期字体、标签与光点仍完整；不得自动启动浏览器。

### 完成标准

- 34 个省名、34 个行政中心光点和必需岛礁名称全部呈现。
- 字体子集完整、离线、体积受控，缺字和载入失败路径可验证。
- 所有资产校验、构建、lint、测试和人工验收通过，此前主图政治要素无回归。
- 没有坐标/字符串复制、在线字体、完整 CJK 包、实时碰撞系统或业务 tooltip。
- 可以创建只包含标签、光点和字体子集结果的 Git checkpoint，代码库可安全进入 TASK-017。

### 回退边界

回退本 TASK 只会移除主图文字标签、省会光点和字体子集；所有省界、政治线/点与领域地点数据仍保持完整。
