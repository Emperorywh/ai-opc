## 任务描述

### 可验证结果

海平面处呈现覆盖主图海域的半透明深蓝青动态水面，水面具有细微连续流动，且可透见保留负高程的大陆架，形成近岸较浅、远海较深的过渡。

### 输入

- SPEC §3.1、§3.5、§4.3、§5.1、§7.3–§7.4、§12.5。
- TASK-003 的含负高程生产资产。
- TASK-007 的地图世界包围盒。
- TASK-008 的海陆/高程查询语义。
- TASK-009 至 TASK-012 的地形与场景。

### 输出

- 位于 `y=0` 的海面，覆盖目标海域且不改变水下地形网格。
- 深蓝青半透明材质，透明度基线位于 0.55–0.7；通过统一渲染时钟驱动双层流动扰动或等价低成本微波效果。
- 水下地形继续使用高程色阶的深海颜色，透过海面可见大陆架深度层次。
- 动画每帧只更新必要 uniform，不在运行循环中创建几何、材质或临时大对象。
- 海面作为独立渲染层，不承担地表分层设色、相机、边界或加载状态职责。

### 实现约束

- 海面必须与地形高程使用同一米制 `y=0` 海平面，不得用视觉偏移掩盖坐标不一致。
- 不得把负高程钳制为 0，不得以不透明平面遮住大陆架，也不得让海面参与陆地色阶。
- 动画必须使用 R3F 统一帧循环/时钟，不建立独立漂移时钟。
- 禁止运行时下载法线贴图；所需效果应由静态本地资产或 shader 计算完成。
- 具体波形实现属于内部选择，但应保持细微、不喧宾夺主且可测试其输入状态。
- 新增或修改的代码必须用多行简体中文注释解释海平面、透明混合、统一时钟和无分配循环；不得主动格式化无关代码。

### 验证方式

1. 执行 `pnpm test`，预期海面高度、覆盖范围、透明度边界和统一时间输入契约通过。
2. 自动化验证负高程仍由地形层保留，海面层不会改写高程或色阶配置。
3. 执行 `pnpm lint` 与 `pnpm build`，预期 shader、透明材质和场景装配通过。
4. 人工执行 `pnpm dev` 后自行打开页面；预期海面连续轻微流动，近岸到远海呈现由浅到深层次，可隐约看见水下地形。
5. 人工旋转和缩放后观察，预期无明显透明排序闪烁、穿插或水面覆盖陆地异常；不得自动启动浏览器。

### 完成标准

- 动态半透明海面和大陆架透视效果已实现并通过人工验收。
- 海平面、透明度和动画输入不变量有自动化覆盖。
- 构建、lint、测试通过，此前地形、色阶、相机与氛围无回归。
- 没有负高程丢失、独立时钟、逐帧对象分配或运行时外网纹理。
- 可以创建只包含动态海面结果的 Git checkpoint，代码库可安全进入 TASK-014。

### 回退边界

回退本 TASK 只会移除海面渲染层；水下负高程地形、色阶、相机和氛围仍保持完整。
