## 任务描述

### 可验证结果

仓库内存在一套可离线消费、标识稳定、几何有效的 34 个省级行政区边界资产，覆盖省、自治区、直辖市、港澳特别行政区和台湾省，并明确标注其非官方审图数据属性。

### 输入

- SPEC §2“区划粒度”、§3.3、§3.6、§5.2、§6、§8、§13。
- TASK-001 的行政区和来源契约。
- DataV.GeoAtlas 省级边界作为基础输入，其已知缺陷仍由后续政治边界完整性 TASK 处理。

### 输出

- 34 个省级行政区的稳定标识、规范名称、行政区类型与 WGS84 经纬度多边形或多多边形几何。
- 所有几何可离线加载，环闭合、坐标合法、行政区标识唯一，并能与后续地点和交互数据关联。
- 数据获取/更新流程、DataV 来源版本或摘要、处理参数和非官方审图免责声明可审计。
- 提供 `pnpm verify:assets -- --scope provinces`，验证数量、标识集合、几何结构、坐标范围和来源记录。
- 测试覆盖岛屿、多多边形、内环以及港澳台等容易遗漏的行政区。

### 实现约束

- 本 TASK 只建立 DataV 基础行政区数据，不得声称已完成九段线、南海岛礁、钓鱼岛、藏南或阿克赛钦的国标完整性；该红线由 TASK-006 独立闭环。
- 不得在运行时访问 DataV；下载和转换只属于离线资产生产层。
- 行政区之间的关联必须使用稳定领域标识，不得依赖数组顺序、中文名称模糊匹配或渲染对象引用。
- 不为旧沙盘数据或其他区划粒度提供兼容分支，不引入市级下钻或业务数据字段。
- 具体资产拆分方式、下载工具和几何库由 Coding Agent 基于实际代码决定。
- 新增或修改的代码必须用多行简体中文注释解释行政区集合、几何修复边界和非审图数据限制；不得主动格式化无关代码。

### 验证方式

1. 执行 `pnpm verify:assets -- --scope provinces`，预期恰好识别 34 个唯一省级行政区，港、澳、台均存在。
2. 执行 `pnpm test`，预期多多边形、岛屿和内环夹具能够保持结构，非法环、越界坐标和重复标识被拒绝。
3. 在测试副本中删除台湾省或重复一个行政区标识，预期资产校验失败并指出具体缺失或冲突项。
4. 执行 `pnpm lint` 与 `pnpm build`，预期静态资产不会引入运行时网络请求或构建回归。

### 完成标准

- 34 个基础省级行政区资产、来源记录和更新方式均已交付。
- 资产数量、标识、几何和关键行政区异常路径均可自动验证。
- 所有仓库级验证通过，前三个 TASK 的结果无回归。
- 没有把政治边界补充数据伪装为 DataV 原始数据，也没有重复行政区目录或运行时下载逻辑。
- 可以创建只包含省级边界资产及其验证能力的 Git checkpoint，代码库可安全进入 TASK-005。

### 回退边界

回退本 TASK 只会移除省级行政区资产和对应校验；地形契约、DEM 流水线和生产高程资产保持完整。
