title: 实现省级悬停焦点闭环
---

## 任务描述

### 可验证结果

鼠标悬停任一省级行政区时，该省边界加亮加粗、对应省名标签放大并置顶；移动到其他省份时焦点原子切换，移出地图或进入海域时全部恢复，且没有 click 行为。

### 输入

- SPEC §2“省份交互”、§4.2、§12.7。
- TASK-004 的行政区稳定标识与多边形。
- TASK-007 的投影与屏幕/世界反查契约。
- TASK-014 的可寻址省界。
- TASK-016 至 TASK-017 的标签状态。

### 输出

- 从指针命中地形后的地理位置确定所属省份，正确处理多多边形、岛屿、内环、边界相邻和海域无归属。
- 单一显式 `hovered province` 领域状态，作为边界样式和标签样式的唯一交互输入。
- 悬停省份边界提升亮度/线宽，标签提升缩放/层级/可读性；其他省界可轻微压暗，但不能成为识别当前焦点的必要条件。
- 移出、海域、无命中和组件卸载都会恢复无焦点状态；快速跨省不会残留多个高亮。
- 自动化测试覆盖拾取和状态转换，人工验收覆盖实际视觉反馈。

### 实现约束

- hover 状态必须以稳定行政区标识表达，不得保存 Three.js 对象引用、中文名称匹配或多组件布尔组合。
- 拾取/点在多边形内判断属于交互领域能力，边界和标签视图只能消费最终状态，不得各自做一次拾取。
- 不实现 click、下钻、飞焦、业务 tooltip 或业务数据绑定。
- 省界 draw call 优化不得牺牲单省样式寻址；若现有结构不支持，应在本 TASK 做必要重构，不得叠加第二套边界。
- 遮挡透明度与 hover 放大必须通过明确优先级合成，不能互相覆盖造成闪烁。
- 新增或修改的代码必须用多行简体中文注释解释拾取流程、单一状态源、样式合成优先级和恢复不变量；不得主动格式化无关代码。

### 验证方式

1. 执行 `pnpm test`，预期普通省份、多岛省份、内环、相邻边界、海域和地图外点位的所属判断正确。
2. 自动化驱动 `无→A省→B省→海域→无`，预期任一时刻最多一个焦点，边界和标签派生状态同步恢复。
3. 自动化触发 click，预期不发生状态迁移、相机飞焦或数据加载。
4. 执行 `pnpm lint` 与 `pnpm build`，预期无回归。
5. 人工执行 `pnpm dev` 后自行打开页面，快速跨越多个省份并移出地图；预期加亮、加粗、放大、置顶与恢复稳定一致，不得自动启动浏览器。

### 完成标准

- hover 拾取、单一焦点状态和跨视图反馈形成完整闭环。
- 正常、海域、边界、快速切换和 click 无行为均有验证。
- 构建、lint、测试和人工验收通过，边界贴地与标签遮挡无回归。
- 没有重复拾取、对象引用状态、残留多高亮、click 行为或跨层耦合。
- 可以创建只包含省级 hover 结果及必要边界重构的 Git checkpoint，代码库可安全进入 TASK-019。

### 回退边界

回退本 TASK 只会移除省级拾取、焦点状态及其边界/标签反馈；静态省界和标签保持 TASK-017 完成时的行为。
